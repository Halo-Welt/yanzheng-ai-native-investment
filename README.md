# 研证 · AI Native 投研证据审校

输入研究摘要 → DeepSeek 拆解原子主张 → 受限证据检索与数值校验 → 标记事实、冲突、推断与违规表达 → 用户查看原文并复核 → 导出带证据与处理记录的报告。

[Web产品](https://yanzheng-investment-research.halowelt.chatgpt.site) · [源代码](https://github.com/Halo-Welt/yanzheng-ai-native-investment) · [五项交付清单](docs/DELIVERY.md) · [1分49秒产品演示](https://github.com/Halo-Welt/yanzheng-ai-native-investment/releases/tag/demo-v1)

面向小型研究团队的初级研究员和复核人员，定位在研究内容进入晨会或内部发布之前。界面采用同花顺风格的红、白、深灰主题，产品为独立笔试作品。

## 运行

需要 Node.js 22+。

```bash
npm ci
cp .env.example .env.local
# 在本地编辑器中设置 .env.local 的 DEEPSEEK_API_KEY；不要提交密钥
npm run dev
```

浏览器访问 http://127.0.0.1:5173 。开发前端5173端口将 `/api` 代理至3001端口。无密钥时可以主动选择「规则演示」体验完整的检索、核验、人审、导出流程；该模式不调用大模型，绝不自动冒充真实AI。

```bash
npm test
npm run build
```

`npm run preview` 用于前端构建预览，完整开发/API测试请使用 `npm run dev`。本次交付托管于 Sites / Cloudflare Worker，运行 `npm run build:sites` 会把前端静态资源与后端打成单个 Worker；托管凭证用秘密环境变量注入。`node scripts/preview-worker.mjs` 可在4174端口检查相同构建。另保留 Vercel `api/*.mjs` 服务端函数与 `vercel.json`，方便后续迁移。

## 环境变量

| 变量 | 用途 | 默认 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 仅服务端读取的模型密钥 | 无 |
| `DEEPSEEK_BASE_URL` | HTTPS模型服务地址 | `https://api.deepseek.com` |
| `DEEPSEEK_MODEL` | 模型名 | `deepseek-flash` |
| `API_PORT` | 本地API端口；修改时同步Vite代理 | `3001` |

所有密钥文件均被 Git 和部署源文件忽略；环境变量禁止使用 `VITE_` 前缀，以免被打入浏览器。托管运行环境需要单独设置服务端凭证，不能只配置本地文件。

## 为什么这样选题

摘要中的正确数字也可能属于错误的字段。例如贵州茅台2024年**营业收入**1708.99亿元、同比15.71%，与**营业总收入**1741.44亿元、同比15.66%不是同一口径。研究员需要验证完整断言里的公司、年份、指标、数字和单位，而不仅是搜到一个数字。

LLM负责自然语言拆解、同义指标识别、事实与推断分类。确定性工具负责证据白名单、数值、单位、期间及增速比较；规则额外检查全文中的交易建议与收益承诺。最终判断留给人工。实现为一次模型语义拆解加代码编排的有界工作流，**不是模型自主联网或自主交易Agent**。

真实验证：首次混合样例调用完成，用时1757ms、630 tokens，4个数值事实有依据，1个比较冲突、1个推断、2个禁止表达。原始结构化报告见 [docs/live-audit.json](docs/live-audit.json)。这是一次技术验证，不代表总体准确率、业务节省时间或投资表现。后续运行结果可能因模型输出与服务状态变化而不同。

## 数据与证据

首版使用 [贵州茅台2024年年度报告](https://static.cninfo.com.cn/finalpage/2025-04-03/1222993920.PDF#page=5) 的8个已人工核验公开字段，涵盖2024年度主要指标和年报列示的2023年度可比金额。每条证据保留原始数值、元/亿元单位、报告年度、披露日期、获取日期、字段口径和PDF页码。**这是历史快照，不是最新财报或实时行情。**

优先调查了题目指定的扶摇与iFinD。扶摇匿名财务请求返回业务码2003 / `Missing X-api-key`，不能视为成功；未取得iFinD可调用工具或授权。不虚构接入结果，详见 [来源与接入记录](docs/SOURCES.md)。

## 核心操作

1. 载入示例或输入摘要，选择DeepSeek AI或规则演示。
2. 运行审校，查看逐条主张、风险类别和实际工具轨迹。
3. 打开证据，核对报告期间、字段口径、单位及原文链接。
4. 逐项人工复核并填写处理备注。原有缺证或冲突不会因人工勾选变为事实成立。
5. 导出审校草稿或满足条件的报告；带出未解决问题与复核记录。
6. 选择缺失、失败、失效、冲突演练检查产品如何显式拒绝正常结论。

输入将发送给DeepSeek进行语义分析，请仅使用公开或匿名构造信息。首版无服务端档案库；浏览器历史保存行为以页面提示为准，可在审校记录中删除。

## 边界与未做事项

- 覆盖一个公司、有限历史字段，不支持任意公司、任意指标、任意PDF自动解析。
- 不做确定涨跌预测、收益承诺、直接买卖建议、下单或投资适当性判断。
- 合规表达识别是辅助质量治理，存在误报和漏报，不替代正式合规审核。
- 每次最多提取16条主张，不保证穷尽全文；未提取内容不代表已核验，仍需人工阅读全文。
- 规则演示不能证明LLM语义泛化；故障选择是人为注入，不能据此断言实际源数据异常。
- 无多人权限、服务端协作、共享配额、持久审计和实时数据订阅。进程内IP限流不替代生产级网关。
- 尚无真实研究员对照实验。效率提升、问题检出率等数字均为后续验证目标，未冒充实测成果。
