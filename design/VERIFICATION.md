参考：concept.png（1536×1024完整主屏）。用户随后明确要求主题接近同花顺，主色由森林绿覆写为红#d93036。红色改版图像生成因网络失败未获得新图，实施依据为原图布局和用户给定主题。最终渲染：../docs/screenshots/desktop.png、conflict.png、mobile.png、mobile-results.png。

使用Playwright CLI截图，因内置Browser的browser-client.mjs安装缺失而替代；在1536×1024原图尺寸与393×852移动视口完成检查。主Agent在同一轮验收中用view_image直接查看原概念图与最终实现截图，并检查移动与冲突证据状态。

| 对照点 | 参考/要求 | 最终实现及处理 |
| --- | --- | --- |
| 布局 | 侧栏、顶栏、摘要/结果/证据三列、下方工具日志 | 保留结构，212px侧栏、60px顶栏；结果和证据独立滚动，移动改为单列 |
| 配色 | 原图白底冷灰分隔；用户要求同花顺主题 | 白底保持，主色按用户改红；语义支持绿/风险琥珀及红；无渐变或覆盖滤镜 |
| 主文案 | 让每一条观点，回到证据。及原CTA/导航 | 核心文案保留；无新增营销眉题。模式/异常/导出/隐私说明是题目必需功能扩展 |
| 字体 | 中文清晰、金融工具适当紧凑 | 主标题30px（原设计规范32px的紧凑调整），摘要14px、主张13px、核验解释/原始字段12px；控件显式指定字号 |
| 证据 | 侧栏字段、原始值、年度、披露日、口径、页码 | 修复原图错误第9页为真实第5页；保留原始元值、具体definition，链接无重复锚点 |
| 图形与容器 | 简洁线框图标、细线、低圆角面板 | Lucide outline、6px面板；品牌改独立“研”字红块，不使用同花顺商标；没有以截图代替交互 |
| 运行状态 | 完整闭环与可解释工具 | 原图虚构时间戳/进度去除，使用实际API trace；空态不预先伪造报告 |
| 响应式 | 窄屏可操作 | 393px无横向溢出；顶部导航、单列摘要/结果/证据，人审与来源均可访问 |

首屏文案差异核对：标题、导航、主CTA与数据来源核心含义保留。允许的新增包括真实AI/规则选择、故障演练、字数与隐私说明、输入变更提示、导出和人工复核状态；删除了概念图中不真实的初始报告和虚构时间。金融数值、披露日、页码以实际来源覆盖生成图文字。

已修复：初版过小的10px证据正文、生成图错误页码、重复页码URL、导出换行、历史恢复缺少输入快照。核心路径已实际验证：输入→真实AI→证据比较→人审备注→导出→可选保存/清除→历史恢复→编辑后失效提示→错误后显式降级。

实现已按概念布局与用户红色主题覆写完成保真核验。剩余有意偏差为上述用户主题、真实数据与必要交互调整；未发现未处理的阻断性视觉或交互问题。
