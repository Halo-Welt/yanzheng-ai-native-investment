# 独立审查与修复复验记录

审查日期：2026-11-04（Asia/Shanghai）。审查角色：产品 / 数据 Agent 兼独立验收 Agent。范围为 `server/core.mjs` 的只读审查、公开数据元数据核对和本地回归验证；后端修复由另一名 Agent 实施。验收过程没有读取 `.env`、没有使用真实模型凭证、没有调用付费模型 API。

## 发现及修复

审查通过规则演示与 mock extractor 复现错误。mock extractor 会刻意输出错误公司、字段、年度或单位，检查确定性核验是否能阻止模型的错误映射，而非默认模型永远正确。

| 问题 | 修复前实际表现 | 修复方式 | 最终复验 |
| --- | --- | --- | --- |
| 历史数据冒充最新 / 当前 / 今年 | 全文另有 2024 年时，“最新营业收入 1708.99 亿元”被支持 | 当前时点词与历史证据隔离 | 3 条回归通过 |
| 公司字符串包含关系 | “贵州茅台供应商甲公司”被当作贵州茅台 | 精确公司别名与原句主体校验 | 回归通过 |
| 同全文其他公司 | 全文出现茅台后，宁德时代相同数字被支持 | 局部公司主体绑定 | 回归通过 |
| 模型映射到错误字段 | 原文营业收入被映射为营业总收入或归母净利润，只因数字相同就通过 | 数字与原句指标绑定 | 2 条回归通过 |
| 报告年份与指标年度混淆 | 同句既有 2023 年指标又有 2024 年报告，模型提错年度仍可通过 | 目标数字之前的局部年度绑定 | 回归通过 |
| 跨公司 / 年度比较 | 宁德时代 2025 年增速判断引用茅台 2024 年数据 | 按主张自身上下文检索比较证据 | 回归通过，不附错误证据 |
| 模型漏提风险同义词 | “建议购入”“逢低吸纳”“百分百上涨”在模型漏提时未被独立规则拦截 | 补充独立风险表达规则 | 3 条回归通过 |
| 同句跨字段借数字 | 收入 2000 亿元、利润 1708.99 亿元的整句被误提为收入 1708.99，仍通过 | 将数字绑定到最近所属字段 | 回归通过 |
| 同句逗号后切换公司 | 逗号后宁德时代的收入沿用前半句茅台主体 | 按目标数字所在指标的局部子句回溯主体 | 追加回归通过 |
| 同句跨字段借单位 | 收入 1708.99 元、利润 862.28 亿元，被模型误提为收入 1708.99 亿元仍通过 | 将数字后原始单位与模型单位精确比较 | 追加回归通过 |

前 12 项回归初次执行时全部失败；第 13 项通过独立复现后加入。第一轮修复后独立执行挑战集 13/13、合并测试 29/29 通过。随后在修复代码中复现最后两项同类边界问题并补测试，交由后端修复。最终对 15 项挑战及全部 31 项测试重新执行，均通过。

另行核验的“2025 年指标引用 2024 年数据”“同比下降 15.71% 被误作增长”“营业收入与营业总收入数值交换”“保本 20%”“预测必然上涨”等输入，在最初检查中已经被阻止或标记；其中部分已有后端测试覆盖，没有重复编写。
