## 演示中的关键口径差异

[年报第 8 页](https://static.cninfo.com.cn/finalpage/2025-04-03/1222993920.PDF#page=8)“五、报告期内主要经营情况”披露营业总收入 **1,741.44 亿元**、同比 **15.66%**。它与营业收入 **1,708.99 亿元**、同比 **15.71%** 是不同字段。

因此“营业总收入为 1,708.99 亿元”即使数字能在报告中检索到，字段绑定仍然错误。这正是本产品把语义抽取、结构化字段与确定性核验结合起来的原因。第 8 页同样列有“利润表及现金流量表相关科目变动分析表”，再次披露营业收入，而非把两个口径合并。

证据库只保存 8 个数值字段、简短摘录、定义和原文定位；没有把完整年报或受限数据纳入源码仓库。

## 获得授权后的验证计划

1. 从扶摇利润表接口或 `get_a_share_financials_income_statements` 开始，在服务器配置授权；选择明确年度而不是直接使用最新一期。
2. 同时校验 HTTP、业务码、字段为空、币种、报告期、披露日；保留原始字段名与请求标识，不记录密钥。
3. 将营业收入与归母净利润同年报原文交叉比较。若口径、披露批次或数据修订冲突，显示双方值并转人工复核。
4. 使用 iFinD 扩展新闻和政策证据时，将事实时点、发表时间与检索时间分开记录，并增加原文定位。
5. 在获得数据再分发许可前，只展示授权范围内的数据，不把原始响应写入公开仓库。
