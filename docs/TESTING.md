## 真实 DeepSeek 验证

首次真实调用的结构化报告保存在 `docs/live-audit.json`。模型 `deepseek-flash`，一次模型调用，1757ms，630 tokens。8个主张分为4支持、1冲突、1推断、2禁止。

后续安全绑定修复后，使用该报告的真实提取片段进行本地重放，主张分布一致。重放不产生新的模型费用，也不能作为第二次独立模型成功来计数。

用户材料仅为构造摘要与公开年报数字。测试不使用真实客户持仓、身份或私有研究内容。

## 独立审查修复

第一轮13个对抗用例先复现缺陷，修复后全部通过。第二轮再发现逗号切换公司和借用其他字段单位两项，添加回归后修复。最终独立15/15、整体31/31。修正由主Agent协调后端Agent完成，未冒充候选人亲自执行的用户研究。

## 浏览器与上线验证

使用 Playwright CLI + Chromium，实际操作本地产品，检查1536×1024桌面和393×852移动视口。内置Browser所需脚本缺失，因而使用此替代路径。

- 真实AI主链路：载入摘要、AI提取、比较冲突、查看两项证据、原文第5页链接，均完成。
- 人审与导出：将第5条设为“需修订”并填写备注，下载Markdown/JSON；实际读取下载文件，确认原文、备注、证据、工具轨迹、草稿状态保留。
- 隐私与历史：默认localStorage无记录；主动启用后保存，关闭后清除；恢复原摘要与逐项人工记录均通过。
- 输入绑定：修改摘要出现旧结果警示，历史草稿不冒充新输入结论。
- 故障界面：规则模式接口失败演练保留0支持/工具错误；浏览器注入HTTP503后显示失败且不残留“AI实际调用”结果，只有用户点击才能切规则演示。
- 移动端：393px单列、输入和结果可操作，DOM实测scrollWidth不超过viewport，无横向溢出。
- 同构部署：Worker静态首页与health均200，正常/缺失/失败/失效/冲突五种API场景独立复查通过。

最终截图保留在screenshots/desktop.png、conflict.png、mobile.png和mobile-results.png。实际下载的构造样例导出为browser-audit.json、example-audit.md。截图是已运行产品的验收证据，不是代替Web交付的静态稿。
